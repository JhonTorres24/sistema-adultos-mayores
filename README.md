# Sistema de Registro y Seguimiento de Adultos Mayores

Proyecto de Programación Web - Universidad Continental (Huancayo, 2026).

## 📝 Descripción del Proyecto
Aplicación web Full Stack desarrollada para resolver la problemática del seguimiento sociosanitario de adultos mayores en situación vulnerable. Permite registrar datos, llevar un historial de visitas y generar alertas tempranas para casos críticos.

## 🛠️ Tecnologías Utilizadas
*   **Frontend:** Angular, Bootstrap 5, SweetAlert2.
*   **Backend:** Python, FastAPI, SQLAlchemy, JWT (Autenticación).
*   **Base de Datos:** PostgreSQL.

## 🚀 Cómo ejecutar el proyecto localmente
1. Clonar el repositorio.
2. En el Backend: crear entorno virtual, instalar requerimientos (`pip install -r requirements.txt` - *opcional*) y configurar PostgreSQL en `database.py`.
3. En el Frontend: ejecutar `npm install` y luego `ng serve`.
